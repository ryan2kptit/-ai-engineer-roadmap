Quiz kiểu phỏng vấn cho: $ARGUMENTS (một note id, hoặc "phase N").

1. Đọc note(s) tương ứng và note base liên quan.
2. Hỏi 5–7 câu, tăng dần độ khó, trộn base + claude; ít nhất 1 câu "với OpenAI/Gemini thì sao", 1 câu system design/trade-off, 1 câu gotcha thực tế.
3. Hỏi từng câu, chờ trả lời, chấm ngay: đúng / thiếu gì / sai ở đâu. Không gợi ý đáp án trước.
4. Kết luận: pass (≥ 80%) hay chưa; liệt kê lỗ hổng cụ thể và note nào cần bổ sung.
5. Pass → đề nghị đổi `stage: done` (kèm `completed`, `project`).
