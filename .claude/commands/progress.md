Trả lời "làm đến đâu rồi".

1. `node scripts/progress.mjs`.
2. Tuần hiện tại theo `content/plan/weeks.md` và ngày hôm nay; so với tuần có log gần nhất → đúng nhịp hay trễ bao nhiêu tuần.
3. Đọc phase file tuần hiện tại, đếm checkbox chưa tick.
4. Trả lời ≤ 10 dòng: tuần/phase, % theo layer, note đang learning, 3 việc tiếp theo, 1 cảnh báo nếu trễ hoặc note claude đang chạy trước base.
